# Submission checklist (from the professor's project brief)

**University:** Université Abdelmalek Essaâdi  
**Faculty:** Faculté des Sciences et Techniques de Tanger (FSTT)  
**Project repository:** https://github.com/AcharkiMd/agentic-scientific-review-ai

- [ ] **Source code** uploaded to a GitHub or GitLab repository (the local ZIP alone is NOT submission).
- [ ] **README.md** documents development and setup, installation, configuration, execution, and usage.
- [ ] **Working system** implements multiple coordinated agents and RAG with transparent decisions.
- [ ] **Configurable review protocol template** is present and aligned to PRISMA workflow concepts.
- [ ] **Real-topic demonstration** is recorded. Prefer an actual live review against scholarly indexes, after verifying citations and scientific outputs.
- [ ] **Technical report and user guide** accompany the source and discuss limitations.
- [ ] **Evaluation results** cover completeness, screening accuracy against independent reference labels, inter-agent consistency, and measured time comparison; mark unavailable metrics as not evaluated.
- [ ] **Video demonstration** submitted, duration **no more than 3 minutes**.
- [ ] **Team of no more than 5**; each student's true individual contribution described in the final report.

## Caveat

The included end-to-end fixture demo is synthetic and **cannot, by itself, satisfy a scientific demonstration on real publications**. Running live mode with real paper metadata/full texts and validating the outputs is still required for a defensible scientific submission.
